# Portfolio Site

A static portfolio and case-study site for the Happy Hour Finder project.

The live GitHub Pages site is served from the **repository root** of the `portfolio-site` branch
(`/index.html`, `/case-study.html`, `/styles.css`, `/site-assets/`). This folder mirrors those files
for reference; edit the root copies and re-sync.

## Pages
- `index.html` — portfolio landing page (hero, highlights, featured project, experience, approach, about, contact)
- `case-study.html` — Happy Hour Finder case study (problem, product, pipeline diagram, guardrails, architecture, quality metrics, screens, tradeoffs)
- `styles.css` — shared visual system

## Assets
`/site-assets/` holds web-optimized screenshots (WebP), the favicon, the Apple touch icon, and the
1200×630 social preview image. Screenshots are exported from `docs/screenshots/`; the Explore
screenshot is cropped to remove a development-mode error toast.
